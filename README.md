## 🩸 Red Love – Blood Donation Platform

🔗 Live Website

👉 Live URL: [Live-Link](https://client-blood-donation.netlify.app/)

## 📌 Project Purpose

Red Love is a community-driven blood donation platform designed to connect blood donors with people in urgent need.
The platform simplifies blood donor registration, searching, and emergency requests while ensuring a secure, user-friendly experience.
It also allows users to contribute small funds to support medical emergencies and social welfare initiatives.

## ✨ Key Features

🧑‍🤝‍🧑 User Authentication (Login / Register)

🩸 Blood Donor Registration & Management

🔍 Advanced Donor Search (by blood group, district, upazila)

📊 Real-time Donation Requests Tracking

💰 Funding & Donation System

🛡️ Secure User Data Handling

📱 Fully Responsive Design (Mobile, Tablet, Desktop)

🎨 Modern UI with Tailwind CSS & DaisyUI
